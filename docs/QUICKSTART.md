# 开始使用 TalkTact Fork

项目介绍与 Fork 特性见 [README](../README.md)。这里集中放安装和使用步骤。

## 选择安装包

- [Releases](https://github.com/Sakura520222/TalkTact/releases) 提供已发布的版本，功能以该版本说明为准。
- [Build 工作流](https://github.com/Sakura520222/TalkTact/actions/workflows/build.yml) 提供开发构建。在成功的运行中选择对应分支的 APK artifact；它是调试包，签名可能与发行包不同。
- [0.9.0 正式版](https://github.com/Sakura520222/TalkTact/releases/tag/v0.9.0) 包含五页重写、液态玻璃底栏和微信 / QQ 新浮窗；早期 `0.8.12-fork.1` 测试版不包含这些改动。

Android 需为 **12 及以上、arm64**，模块框架需提供 **libxposed Modern API 102**。高品质折射需要 Android 13 及以上；低品质或能力不足时保留普通卡片。

## 从原版切换

本 Fork 保留 TalkTact 名称和包名 `io.github.shibry88_netizen.talktact`，使用独立签名，不能与原版并存。

1. 在旧版的备份入口导出配置与角色。
2. 如需迁移 API Key，主动选择在备份中包含凭据，并妥善保存文件；默认备份不包含 Key。
3. 卸载旧版，安装本 Fork，再导入备份。

## 启用微信

1. 在框架中启用 TalkTact，作用域选择微信，然后重启微信。
2. 打开 TalkTact，在「设置 → 接口与模型」填写接口、Key 和模型。
3. 在状态页运行接口自检，或到「试一试」用合成聊天确认候选回复能正常生成。
4. 回到微信聊天页，点击「军师」查看卡片。关闭「自动分析」后，仍可在卡片中手动识别。

设置会通过框架同步；更换模块 APK 或作用域后需要重启宿主。状态页中的模块自身激活探针与宿主运行状态是不同的检查项。

## 启用 QQ

1. 在「设置 → QQ 浮窗」开启接入，并同意框架的 QQ 作用域请求。
2. 确认框架作用域包含 QQ，重启 QQ。
3. 打开聊天页，在卡片中主动识别。

QQ 默认关闭，始终手动识别。QQ 的角色档案和白名单按宿主隔离；微信的会话列表拉取入口仍只处理微信。

## 使用卡片

- 点候选回复填入输入框，长按复制；最终发送由你完成。
- 「再短点」「更正式」「换个说法」仅更新选中的候选。
- 点收起按钮关闭卡片；新结果、报错和敏感提示不会自动展开。
- 遇到敏感提示时，只有主动放行当前内容才会继续分析。切换会话后需要重新确认。

## 隐私与排查

聊天上下文会发送到你配置的模型接口。原始图片仅在本机识别，识别出的文字会随上下文发送；OCR 需要本地代理配合，读取不到的内容保留占位回退。当前分支仍存在部分图片页读字失败，以及强制冷启动时出现过无响应的问题，尚未完成全部场景验证。

接口不通时先检查「试一试」和接口自检。宿主内读取异常可使用浮窗的「诊断」，再到 App 诊断页查看。诊断可能包含真实聊天，分享前应检查并脱敏，不要公开上传原始诊断包。
