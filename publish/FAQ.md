# 常见问题 · TalkTact

## 会不会被封号？

本模块只读屏幕上的消息、只把候选回复填进输入框，**不自动发送、不改聊天记录、不群发**，
它会修改微信 / QQ 客户端行为，
**风险由你自己评估** —— 建议先用小号试。

## 要不要 root？

当前 Fork 在已 root 的手机上配合提供 Modern API 102 的 LSPosed 完成了部分实机验证。
免 root 的补丁方案取决于框架兼容性与宿主能否正常运行，当前 Fork 尚未逐一验证。

## 支持哪些微信版本？

见 [当前分支的兼容进展](../README.md#兼容与进展)。Android 16、微信 8.0.66 与 QQ 9.1.60 上已检查浮窗材质和交互；图片页读字及强制冷启动无响应仍在排查，不能据此保证所有聊天场景。

## 支持 QQ 吗？

0.9.0 支持可选 QQ 接入，默认关闭、始终手动识别。开启「设置 → QQ 浮窗」，获得框架作用域后重启 QQ。
QQ 档案与白名单和微信隔离，完整步骤见 [开始使用](../docs/QUICKSTART.md#启用-qq)。发行包是否包含该功能以对应版本说明为准。

## 模块列表里显示「不兼容 / 没加载」？

框架版本不够。本模块用 libxposed Modern API（`minApiVersion=102`），LSPosed / Vector 需要足够新的版本，先升级框架。
**原版 LSPatch 不支持**（它只认 legacy 模块），请改用 NPatch。

## 装了模块，微信里什么都没出现？

1. LSPosed「模块」里启用本模块，**作用域必须勾微信**，然后**强杀微信**重开；
2. 打开 App 状态页，查看框架连接、模块激活与宿主运行检查；
3. 浮窗出现但读取异常时，可使用「诊断」或长按标题保存诊断。诊断可能含聊天，分享前应检查并脱敏。

## 读不到消息 / 一堆 `[图片/表情/语音]`？

多半是消息列表选错了，或者气泡识别失败。长按卡片标题拿诊断 —— 里面有实际读到的内容，发出来就能调。
（深色模式、换主题、超大字号都可能影响识别。）

## 为什么没有候选回复？

到「试一试」页粘一段聊天验证接口：能看到延迟和 token 就说明接口通。
接口报错会直接告诉你下一步改什么（401 = Key 不对，404 = 地址要写到 `/v1`，429 = 被限流）。

## API Key 会不会泄露？

Key 明文保存在 App 私有目录，请求模型时用于对应接口的鉴权。启用本地代理后，两套服务商 Key 均不会镜像给宿主进程。
具体数据边界见 [隐私说明](PRIVACY.md)，备份默认不包含 Key。

## 群聊支持吗？

能带出昵称，但微信群聊的行结构在版本间变化大，**目前只有单聊可靠**。

## 这个模块不会做什么？

自动发送、抢红包、修改/删除聊天记录、群发、导出聊天记录、读取微信数据库 ——
这些都不做，也不打算做。
