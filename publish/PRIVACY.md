# 隐私说明 · TalkTact

一句话：**它只读你此刻看得见的那几行聊天，发到你自己填的接口地址；不自动发送、不上报、不读微信 / QQ 数据库。**

## 它会读什么

- 只读**你当前打开的那个聊天页**上、屏幕上看得见的最近几条消息 —— 纯读界面控件，
  **不碰微信 / QQ 数据库**（不碰 `EnMicroMsg.db`），也不读别的聊天。
- 「本人」的说话风格 skill 打开后，另外只采集**你自己发出去**的文本消息
  （跨聊天合并，上限 400 条；关掉开关会清掉原始样本）。
- 图片 / 表情 / 语音读不到内容，只记一个 `[图片/表情/语音]` 占位。

## 它会发到哪

- 聊天记录 + 角色档案 + skill 提示词 → **你在「设置 → 接口与模型」里自己填的那个接口**
  （OpenAI 兼容）。它可能是官方接口，也可能是第三方中转 —— 请自行确认可信。
- 「归属地」那一行的省份是模块**唯一**会主动访问的第三方服务（`ip.useragentinfo.com`）；
  取不到就显示 `null`，失败不影响任何功能。
- 除此之外**不做任何上报**：没有统计、没有崩溃收集、没有埋点。

## 它把东西存在哪

- 全部在本机 App 私有目录（`/data/data/io.github.shibry88_netizen.talktact/`）：
  接口地址与 Key、角色档案、说话风格 skill、调用次数统计。
- **API Key 明文保存在应用私有目录**，系统云备份关闭。启用本地代理时，两套服务商 Key 都不会镜像给注入进程，宿主只使用随机代理 token。
- 模块**不会**把聊天内容写进日志：LSPosed 日志里只有「连上了 / 出错」这类状态行。

## 怎么删

- 单个角色：「角色」页 → 点进那个角色 → 清空记录 / 删除角色。
- 说话风格：「本人」页 → 清空记录；关掉开关会同时清掉采集的原始样本。
- 全部：卸载 App（或清应用数据）—— 所有数据都在它自己的私有目录里。

## 它明确不做的事

- **不自动发送**：候选回复只填进输入框，最后一下由你按。
- 不抢红包、不自动回复、不群发。
- 不修改、不删除、不导出任何聊天记录。
- 注入只针对微信和 QQ 的精确主进程，另保留模块自身激活探针，不处理其他应用。

## QQ 与浮窗背景

QQ 默认不读取；开启 QQ 浮窗并获得框架作用域后，只有主动识别才读取当前聊天、处理 OCR 或请求模型。QQ 档案和白名单使用独立宿主身份。App 中原有的批量拉取与抓取微信指令仍只发送给微信；QQ 可使用浮窗的诊断按钮和按宿主手动添加白名单。

玻璃背景只在同一窗口的 GPU display list 中引用宿主内容，不读回截图、不写文件、不上传；暂停、离开或白名单拒绝时清理引用。低品质或平台不支持时使用可读实底。仅调试构建含固定合成预览及点击计数，不含用户聊天或配置。
